# DSH 原生对话集成

4.4.1 把玻尔工作台放进 DSH 原生对话页的输入区上方，并移除了插件自己的聊天框。自定义问答界面不再承担聊天职责，所有用户消息、流式输出、工具过程和错误提示都由 DSH 原版对话展示。

## 入口与悬浮窗

`conversation.input.dock` 中注册了一个始终可见的“玻尔研究网络”折叠栏。展开后使用浏览器顶层 Popover 显示独立研究悬浮窗，不阻断后方原生对话。窗口四边可以拖动位置，四角可以缩放；关闭窗口只收起工作台，不改变原生输入框和消息流。

悬浮窗内部仍是完整工作台，但使用紧凑布局：隐藏重复品牌区、项目摘要、图谱标题和说明，保留搜索、四个视图切换、双侧网络、节点详情与论文详情。不适合常驻的内容按需展开，而不是全部铺开。

## 卡片进入原生对话

节点详情和论文详情都提供“发送到 DSH 原生对话”按钮。节点也可以从图谱拖到悬浮窗底部发送区，或直接拖到图谱下方。插件先等待论文写入知识库，再通过 DSH 的 `InputActions` 将中文问题写入原生草稿并提交；随后悬浮窗关闭，答案和工具调用由 DSH 原版界面显示。

首次集成曾同时启用浏览器原生 `draggable` 和自定义指针拖动，导致拖拽手势被截获。4.4.1 已移除原生拖拽，并在 `window` 级监听指针释放，使拖出 SVG、拖出发送区和拖到原生输入区都能被捕获。

## 论文摘要与思维导图

实时检索或节点展开后，插件把论文题目和摘要批量发送给当前 DSH 模型，生成英文概括、中文对照和关键发现，并缓存在本地。4.5.2 采用批量生成、逐篇重试、题目级保守概括和 DSH 翻译服务四级保底，确保每篇论文都有非空中文概要；无摘要时必须明确说明只有题录信息。悬停论文卡显示英文概括与中文对照，正在生成时有明确状态。

论文详情可以生成结构化思维导图。导图节点覆盖研究问题、材料与合成、表征、关键结果、证据边界和下一步验证。选中任意节点后可继续追问，问题会进入原生对话。思维导图只依据题目和摘要，缺少实验细节时会明确写“摘要未提供”。

## 知识库与 DSH 工具

知识库保存在 `C:\Users\sunry\.dsh\bohr-knowledge.json`。收藏论文、发送论文卡片或追问思维导图时都会写入。Host 注册了只读工具 `bohr_knowledge`，支持 `search`、`list` 和 `get`，参数根节点为标准 JSON Schema 对象。DSH Agent 可以直接调用该工具。

早期版本的工具参数使用了简化属性表，模型 API 因此返回 `tools.function.parameters.type is required and must be "object"`。4.4.1 改为完整对象 Schema，原生对话已恢复正常回答。

## Host 接口

Host 只注册同源 `/bohr-api` 路由，并对跨来源请求做来源检查。接口提供健康状态、多源论文检索、知识库读取/写入、批量中英摘要和思维导图生成。检索优先 OpenAlex，遇到 429 或其他故障自动回退 Crossref，并缓存相同查询；详见 [检索稳定性设计](RETRIEVAL.md)。默认模型来自 `agentDefaultModel.currentSelection()`，当前验证路由为 `deepseek-account / deepseek-flash`。

模型调用失败、摘要为空或 JSON 不完整时返回明确错误，不使用伪造中文或空白成功结果。知识库文件只保存论文元数据、生成摘要和加入时间，不保存对话内容或模型凭据。
