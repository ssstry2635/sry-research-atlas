# 知识网络与化学输入设计依据

早期版本解决节点含义和防重叠后，实际使用仍暴露两点：单侧展开让全图偏向一边，且用户希望自由摆放并让分支向两侧延展。4.4.1 因此采用左右双侧约束布局。

## 双侧层级与渐进披露

研究起点固定在中央。材料谱系进入左半区，制备方法、机会和论文证据进入右半区；更深层节点继续沿所属一侧向外排列。每一侧独立竖直分布，自动布局隐藏跨越中心的次级边，从而避免左右连线互相穿插。水平位置表示探索深度和分支归属，不表示论文相似度。

[Graphviz dot](https://graphviz.org/docs/layouts/dot/) 和 [ELK Layered](https://eclipse.dev/elk/reference/algorithms/org-eclipse-elk-layered.html) 提供了分层、顺序和减少交叉的原则。当前实现不是严格 DAG，而是以材料根节点为中心的双侧约束树：每个顶层分支固定一侧，后代继承该侧。

[Connected Papers 的官方说明](https://www.connectedpapers.com/about)强调有限候选集和路径高亮。当前默认显示当前节点的直接论文证据，可切换全部论文。每页最多五篇，保持纵向间距。材料、同族、方法、论文和机会仍使用不同眉题、图标、边线和元数据。

## 自由拖动与分支聚焦

节点支持直接拖动，位置在当前探索会话中保留。点击非根节点后进入分支聚焦，只保留其上游路径和直接子分支；点击论文不会收起同一分支的其他论文。节点可以从图谱拖到 DSH 原生对话发送区，拖动释放同时支持 SVG 内和窗口级指针事件。

“自动整理”通过缩放控件恢复当前可见节点的双侧布局。节点移动不会触发持续力模拟，避免画布自行漂移。内嵌到原生对话时，工作台放在独立悬浮窗中，减少对消息流的挤压。

“自动整理”会把当前可见节点恢复成稳定的列布局并重置缩放，用于手动拖动过多后快速回到疏朗状态。布局不再是固定不可调整的放射图，也不执行持续力模拟，因此不会自行漂移。

`tests/graph-layout.test.ts` 使用初始网络与二十一篇论文的分页组合，逐对检查所有卡片的实际矩形边界。`tests/graph-drag.py` 在实际浏览器中验证节点自由拖动、自动整理恢复位置和节点点击详情。`tests/e2e.py` 验证八篇实时论文在第一页和第二页分别显示五篇和三篇，并继续检查原文、收藏、持久化和移动端。

## 化学式与语音边界

[MDN Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API) 将语音识别描述为有限可用的浏览器能力，实际实现可能依赖在线服务。插件只在用户点击麦克风后启动识别，提供中文和英文模式、监听状态、错误降级和卸载清理。语音草稿不会自动检索，用户需要核对原始转写、排版候选与查询文本。

[ChemDoodle React 教程](https://web.chemdoodle.com/tutorial/advanced/reactjs-development)和 [ChemWriter](https://chemwriter.com/) 可作为后续结构编辑参考，但当前需求不需要引入完整结构编辑器。[OPSIN 官方说明](https://www.ebi.ac.uk/opsin/)面向 IUPAC 名称到结构的转换，不是中文元素语音解析器，因此当前实现使用本地受限词典和明确的化学式模式，不引入 Java 或 WASM。

[PubChem PUG REST](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest) 可用于后续主动核对化合物记录，但同一分子式可能对应多个 CID。当前插件不会把分子式当作唯一物质标识，也不会自动选择 PubChem 记录。OpenAlex 查询保留线性文本，例如显示值 CsPbBr₃ 对应查询值 CsPbBr3；它是文本检索规范化，而不是精确结构匹配。

普通论文题目保持原样，只有可完整识别的化学式或明确的语音化学式输入才进入转换。无法完整消费的中文、未知元素或不明确内容保留原文。文本输入支持常用元素插入、选中数字转上下标、水合点和电荷标记。`tests/chemistry.test.ts` 覆盖钙钛矿、水合物、电荷、中文元素、英文逐字母语音、普通标题和查询文本转换。

## 实际验收

用户已确认 2.0.0 的化学式文本排版和语音识别可用。2.2.0 进一步针对实际反馈改为定向列布局和自由拖动。自动化测试验证了插件类型检查、Client 构建、化学式转换、列布局边界、论文分页、节点拖动、自动整理和节点选择。用户已在 DSH 中确认 2.2.2 的定向展开、分支聚焦和自由拖动符合预期。当前验收不代表所有浏览器、麦克风、语言和主题组合均已覆盖。
